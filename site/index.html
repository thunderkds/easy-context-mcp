easy-context-mcp

Index once. Search by meaning. Navigate by relations. Return slices with path + lines.

Coding agents spend tokens reading whole files to find one function. easy-context-mcp is a local MCP server that hands the agent only the part it needs. A slice is a piece of one file (a function, a Markdown section or a block of lines), returned with its path and line range.

The flow

A project is one repo or git worktree. Each project has one index: a single SQLite file that holds its slices, their embeddings and the links between them. You build it once. The agent then asks it questions.

Index once

Runs in the background. Nothing leaves your machine.

  1. index_pathThe agent starts an index job for the project.
  2. walk + skipRead the files. Skip secrets, binaries and oversize files.
  3. slicesCut each file by code symbol, Markdown heading or line window.
  4. embed locallyTurn each slice into a vector with a local model. No cloud.
  5. SQLite + edgesSave slices, vectors and graph edges in one file per project.

Ask, as often as you like

Each call reads the index from the first lane.

  1. search_semanticSearch by meaning. Get the top slices, each with path and lines.
  2. get_sliceFetch the full text of one slice.
  3. get_relatedWalk 1 hop to neighbours: calls, imports, links, headings.

Install

You need a local clone. There is no PyPI package yet. Pick one mode.

Stdio mode

One server per Claude Code session. Needs Python 3.10+ and uv.

git clone https://github.com/thunderkds/easy-context-mcp.git
cd easy-context-mcp
uv sync
claude mcp add easy-context -- uv run --directory /path/to/easy-context-mcp easy-context-mcp

Replace /path/to/easy-context-mcp with the absolute path of your clone.

Docker service mode

One shared server for every repo on the machine. Linux with Docker.

mkdir -p ~/.easy-context
export EASY_CONTEXT_WORKSPACE=/abs/parent/of/your/repos
export UID GID="$(id -g)"   # the container runs as your user
docker compose up -d --build service
claude mcp add --transport http easy-context http://127.0.0.1:8767/mcp \
  --header 'X-Easy-Context-Root: ${PWD}'

Keep the single quotes around ${PWD} so the shell does not expand it. Then ask the agent to call index_path.

Six tools

  • index_pathBuild or refresh the index of a project in the background.
  • search_semanticFind slices by meaning. Returns path, lines and a score.
  • get_sliceReturn the full text of one slice.
  • get_relatedList 1-hop neighbours of a slice or file.
  • list_indexesShow every index on the machine and its job status.
  • get_statsShow counts and how much text the server has served.
